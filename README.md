# 互联网黑话翻译器

一个功能强大的微信小程序，专门帮助用户理解和使用互联网行业的专业术语，支持黑话与人话的智能双向翻译。

## ✨ 项目亮点

🎯 **智能翻译** - 自动识别文本类型，一键完成双向翻译
📚 **丰富词库** - 内置652个精选词条，涵盖15大分类（含网络热词）
🔄 **双向转换** - 支持黑话→人话、人话→黑话两种翻译模式
🔍 **智能搜索** - 支持词汇、含义、标签多维度搜索，关键词高亮
⭐ **收藏功能** - 一键收藏词条，分类页直达收藏夹
🔗 **相关词条** - 详情页按同分类/同标签推荐相关词汇
📤 **一键分享** - 词条、翻译结果均可分享给微信好友或朋友圈
📱 **完整体验** - 从浏览、搜索、收藏到详情查看的完整用户流程
🎨 **现代UI** - 渐变设计风格，流畅的用户体验

## 🎯 核心算法

### 智能翻译引擎
- 黑话→人话：词条最长优先单趟替换，无连锁替换；句中释义优先取词条的 `brief` 短释义，无 brief 时取第一义
- 人话→黑话：保守的整段短语替换，不拆解句子，无匹配时保留原文并提示
- 词典与正则在模块加载时一次性构建，翻译为同步单趟替换
- 英文词条大小写不敏感匹配（如输入 `rag` 也能命中 `RAG`）
- 智能文本类型识别（auto 方向自动选择）
- 所有翻译词典均由 `data/words.js` 派生，无硬编码扩展词表

### 数据管理
- **模块化设计**: 数据与逻辑分离，便于维护和扩展
- **分类数据**: `data/categories.js` 存储15个分类信息
- **词汇数据**: `data/words.js` 存储652个词条
- **统一接口**: `utils/data.js` 提供数据访问和操作功能（含今日热词轮换、相关词条推荐）
- **智能搜索**: 支持词汇、含义、标签多维度搜索
- **本地存储**: 收藏、翻译历史和搜索历史本地持久化

## 🛠 快速开始

### 环境要求
- 微信开发者工具 (最新版本)
- 微信小程序开发账号
- Node.js (可选，用于运行冒烟测试)

### 数据结构说明

#### 分类数据 (categories.js)
```javascript
{
  id: 1,                    // 分类唯一标识
  name: '会议用语',          // 分类名称
  desc: '开会时常用的黑话',   // 分类描述
  type: 'jargon',          // 分类类型 ('jargon' | 'professional')
  iconType: 'image',       // 图标类型 ('image' | 'emoji')
  icon: '/images/categories/meeting.png'  // 图标
}
```

#### 词汇数据 (words.js)
```javascript
{
  id: 1,                   // 词汇唯一标识
  word: '赋能',            // 词汇内容
  meaning: '帮助、支持',    // 中文解释（详情页展示）
  brief: '帮助',           // [可选] 翻译句中替换用的短释义（≤15字宽，
                           //   第一义超过15字的词条必须提供）
  example: '我们要赋能业务团队 → 我们要帮助业务团队',  // 使用示例
  categoryId: 1,           // 所属分类ID
  tags: ['帮助', '支持', '协助']  // 相关标签
}
```

### 安装步骤
1. **克隆项目**
   ```bash
   git clone https://github.com/uwakeme/internet_slang_translation.git
   cd internet_slang_translation
   ```

2. **导入项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择项目目录

3. **配置项目**
   - 修改 `project.config.json` 中的 `appid`
   - 确保基础库版本设置为 3.8.10
   - 确保 `images/` 目录包含所需图标

4. **运行项目**
   - 点击"编译"按钮
   - 在模拟器中预览效果
   - 测试各个功能模块

5. **运行冒烟测试**（可选，需 Node.js）
   ```bash
   node scripts/check.js
   ```
   共43项测试，覆盖数据完整性、翻译引擎回归和页面核心逻辑。

### 自定义配置

#### 扩展词汇数据
1. **添加新分类**: 在 `data/categories.js` 中添加分类信息
   ```javascript
   { id: 16, name: '新分类', desc: '分类描述', type: 'professional', iconType: 'emoji', icon: '🔥' }
   ```

2. **添加新词汇**: 在 `data/words.js` 中添加词汇数据（id 取现有最大值递增，当前为 742）
   ```javascript
   { id: 743, word: '新术语', meaning: '中文解释', brief: '短释义', example: '使用示例', categoryId: 16, tags: ['标签1', '标签2'] }
   ```
   - 若释义第一义超过15字，必须提供 `brief` 短释义（冒烟测试会校验）
   - 文本使用全角标点（，；：），不要残留半角 `,` `;`

3. **数据自动同步**: `utils/data.js` 会自动加载新数据，无需额外配置
4. **防重复**: 添加前先搜索确认词条不存在，`node scripts/check.js` 会一次性列出所有重复/脏数据，提交前必须全绿

#### 其他配置
- **修改样式**: 在各页面的 `.wxss` 文件中调整UI样式
- **添加功能**: 在对应页面的 `.js` 文件中扩展业务逻辑
- **翻译规则**: `utils/translator.js` 会自动从词汇数据构建翻译词典，不要在引擎里硬编码新词条
