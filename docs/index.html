词库

652 个词条，随时翻

每一张卡片左侧是黑话，右侧是人话。数据来自 data/words.js，和小程序跑的是同一份。

功能

一个完整的小程序闭环

从浏览、搜索、收藏到详情查看，六个页面各司其职。

翻译

双向智能翻译

黑话转人话、人话转黑话。词条按长度降序合并成一个正则，单趟替换，不会连锁改写。

浏览

15 大分类速览

会议、项目、商务、HR、职场文化、AI、开发、运营……分类页顶部直接进收藏夹。

检索

多维度智能搜索

按词条、含义、标签同时匹配，输入即时联想（防抖 300ms），命中关键词高亮。

详情

释义与真实例句

每条词都带含义、使用示例和标签，部分高频词还配了多场景对话示例。

收藏

收藏与相关词条

一键收藏本地持久化，详情页按同分类、同标签推荐最多 5 条相关词。

分享

分享给同事

词条和翻译结果都能转发到微信好友，详情页和首页支持分享到朋友圈。

快速开始

三步跑起来

原生微信小程序，无需 npm install，无需构建。

1

克隆仓库

源码就是全部，clone 下来即可。

2

导入微信开发者工具

选择「导入项目」，目录指向仓库根目录。

3

改 appid，编译

在 project.config.json 填自己的 appid，基础库选 3.8.10，点编译。

改词库？ 只动 data/words.js 和 data/categories.js。 翻译词典由数据自动派生，不要在引擎里硬编码新词条。
git clone https://github.com/uwakeme/internet_slang_translation.git
cd internet_slang_translation
node scripts/check.js
冒烟测试：45 项断言覆盖数据完整性、翻译引擎回归与页面核心逻辑， 提交前跑一次，全绿再推。node scripts/check.js 会一次性列出所有脏数据。
